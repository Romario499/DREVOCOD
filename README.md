# DREVOCOD

## Код природы. Язык пространства.

## О проекте

DREVOCOD — репозиторий для формирования бренда. Здесь собраны утверждённая основа бренда и материалы подготовки к следующим этапам работы.

## Что уже зафиксировано

- смысл и язык бренда;
- правила работы с подтверждёнными фактами;
- базовая структура для будущих материалов сайта, визуальных активов и документации.

## Структура репозитория

- `brand/` — утверждённые материалы бренда;
- `website/` — будущий исходный код и документация сайта;
- `assets/` — логотипы, изображения и справочные материалы по шрифтам;
- `docs/` — исследования, решения и спецификации.

## Правила работы с фактами

Утверждённый презентационный текст — источник для позиционирования. Язык бренда не является доказательством операционных возможностей. Новые фактические утверждения требуют явного подтверждения или источника в репозитории; неподтверждённое следует помечать как гипотезу, черновик или ожидающее решения.

## Текущий статус

В репозитории находятся основа бренда и подготовительные материалы. Каталог, производственная площадка, продажи и работающий публичный сайт не заявлены как существующие.
